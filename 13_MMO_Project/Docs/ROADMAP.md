- [ ] 외부 연동 — [메트릭과 검증 결과](Plan/004_DummyClient_검증과_메트릭_설계.md#메트릭과-검증-결과-연동), [원본 로그 수집](Plan/005_서버_비동기_로그_설계.md#외부-로그-수집)을 별도로 검증한다. 로컬 smoke의 선행 조건은 아니다.
